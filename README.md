BRINEHAVEN is an open-world crime game set on a tidal island city. Play Nadia Ferro, an ex-ferry pilot who owes $12,400: steal cars, outrun the Harbour Wardens, run seven tide-timed jobs, and watch the causeway flood and drain twice a day — at high tide police boats replace cruisers, at low tide the mudflats open a smuggler's shortcut.

## Run it

```sh
node serve.ts  # serves game/ at http://localhost:8080
```
